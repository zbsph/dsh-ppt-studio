# 流程图（flow）· 手画配方

## 骨架
横向流程：起止 roundRect、中间 rect；末步 accent；**异常分支用回边并标条件**。

## 配方数值
节点 150×64 @ y=208，x=60 起、间距 22（5 个正好排满 60..898）；节点文字 14pt bold 白字居中。
主链箭头 accent 宽 2、端点贴卡边。
回边：自前一步**底边**下探到 y=360 车道 → 左行 → 上扎目标步底边；虚线 + 末端箭头；条件标签放车道**上方**（y=332）。

## 专属坑
1. 回边竖管与标签必须分离（标签独占车道上方的行）。
2. 分支多时改用"菱形节点 + 两条出边"，别把回边画在流程带中间。

## 验收清单
- [ ] 门禁 0 错；[ ] 主链方向一致；[ ] 回边有明确条件标签。

## 本族应调用的机制（先读 mechanisms.md）

- **连边一律 `attach: {from:{ref,side}, to:{ref,side}}`**，不手算像素（含斜边形状 ⇒ 引擎接到真实斜边）。
- 容器（分组/泳道/面板/背景带）**必须把内部元素写进 `contains`**；只声明**相邻层**。
- 折线交给引擎**自动正交化**；刻意斜段（环/放射/漏斗）写 `role: decoration` 或 `roleReason` 声明。
- 箭头前直段 ≥18px 由引擎自动保证；修不了会由 `arrow-end-short-run` 报出 ⇒ **必须读警告**。
- 收工前**逐条解释本页每一条警告**（见 verify.md 铁律之二）。
