# 时间轴（timeline）· 手画配方

## 骨架
水平主轴 + 等距里程碑点 + 标签**上下交替**。

## 配方数值
主轴 line @ y=300、x 70→890、宽 3；里程碑 ellipse 18×18，x=90 起、间距 156。
标签宽 140 居中：名称 14pt bold + 说明 11pt 灰；奇数在上（y=300−96），偶数在下（y=300+34）；刻度短线 1px。
**只高亮一个**关键节点（accent）。

## 专属坑
1. 6 个以上要缩间距或改两行；标签超 140 宽会互压。
2. 全部高亮 = 没有重点。

## 验收清单
- [ ] 门禁 0 错；[ ] 标签不重叠；[ ] 高亮唯一。
