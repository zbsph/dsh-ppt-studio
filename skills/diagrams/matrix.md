# 矩阵（matrix）· 手画配方

## 骨架
**列 = 处置力度，行 = 频次**；每个条目独占一格（别用通用象限名代替处置档，否则丢信息维度）。

## 配方数值
列头 14pt bold @ y=158、宽 230 居中；行标 13pt bold @ x=60、宽 90、行内垂直居中。
格 roundRect 230×120：列 x=160/410/660，行 y=190/330；最高优先级那格用 accent，其余主色；格内 15pt bold 白字。

## 专属坑
1. 每格写进自身 contains；若用外层容器，容器要登记所有格。
2. 3 列 × 230 已是安全区上限。

- [ ] 门禁 0 错；[ ] 列头/行标齐备；[ ] 高亮唯一。
