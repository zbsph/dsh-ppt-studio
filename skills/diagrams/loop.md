# 闭环（loop）· 手画配方

## 骨架
N 个步骤卡沿**椭圆环**分布，箭头沿环指向下一步；环心留空（放文字会被线压）。

## 配方数值
中心 (480,320)，rx=250、ry=132；卡 170×52；角度 = −90° + i×(360/N)。
卡 x = 480 + rx·cosθ − 85，y = 320 + ry·sinθ − 26。
箭头沿"卡心→下一卡心"方向，从**卡边**裁剪（off≈96）到下一卡卡边；高亮其中一步。

## 专属坑
1. 端点必须落在卡边（落卡内 ⇒ 门禁报"卡 × 线"）。
2. 环心留白；必须有中心文字时把箭头改走环外侧。
3. N≥5 时 rx 加到 270、卡宽降到 150。

## 验收清单
- [ ] 门禁 0 错；[ ] 箭头首尾接成环；[ ] 环心无遮挡。
