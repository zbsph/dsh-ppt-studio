# 状态机（state）· 手画配方

## 骨架
横向一行状态卡 + 卡间箭头 + **回边（返工/异常）走卡片外侧车道**；或竖向一列（见下）。
- 5 状态：卡 150×84，y=240，x=60 起，间距 20 ⇒ 卡心 y=282，卡底 y=324。
- 卡内：标题 16pt bold（居中或齐左）+ 副标题 11pt 灰；**卡内文字必须写进卡的 `contains`**。
- 卡间：短箭头，端点**正好落在卡右边到下一卡左边**，y=卡心；颜色取 accent，宽 1.5–2。
- 回边：从源卡**下边**出 → 下垂到 **y=400 车道** → 左行 → 上扎到目标卡**下边**；虚线 + 末端箭头。
- 回边标签放在**车道上方**（如 y=372，高 20），**绝不放车道上**（会压线）。

## 标签（最容易漏）
**主链每条转移都要标签**，放在箭头**上方**（y = 卡顶 − 28），宽 80 居中于箭头中点；只标回边不标主链 ⇒ 内容就丢了（实测）。

## 竖向变体（状态多、副标题长时更好看）
一列 5 卡（470×68 / gap 26 / x=300）；内联编号圆徽 24px @ (x+16, y+12)；标题 x+50/y+10 16pt bold；副标题 x+50/y+38 11pt；卡间用**向下**箭头 3px；回边走左侧 x−40 虚线。
> 实测：这一版观感明显好于横向行（层级清楚、留白够）。优先考虑竖向。

## 该族专属坑
1. **回边竖管压标签带**：竖管必须让开卡下标签带；把车道整体下移（≥ 标签带高 + 8px）。
2. **回边端点画在卡内**（如 x+6）⇒ 门禁报 `unexpected-overlap`；端点必须**落在卡边**。
3. **箭头值只有** `true|false|'end'|'both'`；`'start'` 非法。
4. 自环/回边**不要跨过卡片区**；多回边时按 18px 递增错开车道。

## 验收清单
- [ ] `verifyDeck` 0 错；[ ] 每条边都能**用眼睛指出**从哪张卡到哪张卡；
- [ ] 回边车道不压任何文字；[ ] 卡内文字不溢出（长标签要缩字号或加宽卡）。

## 本族应调用的机制（先读 mechanisms.md）

- **连边一律 `attach: {from:{ref,side}, to:{ref,side}}`**，不手算像素（含斜边形状 ⇒ 引擎接到真实斜边）。
- 容器（分组/泳道/面板/背景带）**必须把内部元素写进 `contains`**；只声明**相邻层**。
- 折线交给引擎**自动正交化**；刻意斜段（环/放射/漏斗）写 `role: decoration` 或 `roleReason` 声明。
- 箭头前直段 ≥18px 由引擎自动保证；修不了会由 `arrow-end-short-run` 报出 ⇒ **必须读警告**。
- 收工前**逐条解释本页每一条警告**（见 verify.md 铁律之二）。
