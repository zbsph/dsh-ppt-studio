# 文字与间距（text-and-spacing）

## 字号级差（一页内固定用这几档）
25（页标题）/ 16（面板标题·卡片标题）/ 13–15（卡内主文）/ 11–12（副标题·注解·标签）。

## 槽位与自动缩字
- 形状内文字**必须写进该形状的 contains**；无内容的形状**省略 contains**（不能写空数组）。
- 文字放不下时：先**从卡片重算槽宽**，再按度量**自动缩字号**（下限 9pt）；宁可缩字，不要溢出。
- 左对齐时槽宽 = 卡宽 − 左侧让位（徽标栏）− 右侧留白；**徽标与标题同行**，不要把徽标竖着居中（会压第二行）。

## 行距与互压
- 同一盒内两行文字框间隔 ≥4px；改了盒高要**同时重排内部两行**（否则 contains 不成立）。

## 对比度
- 文字与底色对比度 **≥3:1**；渐变底要按 **stops 的最亮端与最暗端分别判、取最差**（不许用平均值）。
- 浅色/渐变底上不要默认白字：按对比度**自动选**字色。
