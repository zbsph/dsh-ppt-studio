# 层级树（tree）· 手画配方

## 骨架
根居顶中 → 一级一行 → 叶一行；连线用**正交折线 + 箭头**。

## 配方数值（安全区 60..900 / 60..480）
根 roundRect 200×64 @ (380,124)；一级 170×52 @ y=258（x=90/395/700）；叶 150×48 @ y=380。
连线自根底边 y=188 起 → 主干 y=220 → 落到子节点顶边；**arrow: true**。

## 专属坑
1. 同组子树应加**分组容器**（旧版胜过手画版之处）；容器要把内部所有元素写进 contains，连线穿容器按纪律精确声明。
2. 父盒加高后子文本要一起重排，否则 contains 不成立。
3. 连线端点落在**卡边**，不要落在卡内。

## 验收清单
- [ ] 门禁 0 错；[ ] 每条连线有箭头且贴边；[ ] 组容器登记了内部元素。

## 本族应调用的机制（先读 mechanisms.md）

- **连边一律 `attach: {from:{ref,side}, to:{ref,side}}`**，不手算像素（含斜边形状 ⇒ 引擎接到真实斜边）。
- 容器（分组/泳道/面板/背景带）**必须把内部元素写进 `contains`**；只声明**相邻层**。
- 折线交给引擎**自动正交化**；刻意斜段（环/放射/漏斗）写 `role: decoration` 或 `roleReason` 声明。
- 箭头前直段 ≥18px 由引擎自动保证；修不了会由 `arrow-end-short-run` 报出 ⇒ **必须读警告**。
- 收工前**逐条解释本页每一条警告**（见 verify.md 铁律之二）。
