`git tag -a v<版本> -m "<一句话>"` ⇒ `git push origin main && git push origin v<版本>`。

## 3. 发布到 registry（如走 npm）

`npm publish`（`publishConfig.access = public` ✓）。发布前必须先跑：`npm test` ✓、`npm run verify:products` ✓（本机专用，需 PowerPoint）、`npm run verify:package` ✓。

## 4. 发布说明（可直接用）

**本版要点**
- 复杂图统一走**手写显式 elements + 机制**：`attach` 锚真实边缘（含斜边）、折线自动正交化、箭头前直段 ≥18px、结构关系反验证；引擎不引入编译器。
- 新增门禁 `line-cross-text`（线 × 文字碰撞）。
- 并入 `npm test` 的守卫：13 页回归基线（layout 摘要 + 错警计数 + PNG sha）、红样本 6 条、线×文字 3 条、选项探针 2 条、生成器语法、`lib` ⟷ `src` 逐字节、未知键 warning。
- 本机专用命令：`npm run verify:products`（重出 → 导出 → 渲染 → 与基线比对）、`npm run verify:package`（打包与安装一致性）。
- 回归基线引入 `history` + `--reason`：**改基线必须留痕**，且由断言强制。

**已知限制（请一并告知用户）**
1. 无逐形状样式（阴影/高光/笔触）；开发期的强样式控制选项未纳入本版。
2. 手写几何由作者给出 ⇒ 单页成本更高、批量大 deck 更慢。
3. 生成器检查为**语法级**（运行期类错误仍可能漏网）。
4. 13 页手画回归语料**不随包发布** ⇒ 该回归只在仓库内可跑；包内只发 `lib`。
5. 门禁的 `unknown-key` 目前是**测试链守卫**，尚未进入每页门禁报告。
