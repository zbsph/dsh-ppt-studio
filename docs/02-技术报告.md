## 2. 模块明细

### 2.1 schema.js — 结构与归一化的权威
- 校验（所有错误一次性收集，PptError.messages 数组）：
  - deck：version/1、title、size（[w,h] 或对象）、theme.colors（hex 或 `$ref`）、theme.textStyles、`theme.safeArea`、`theme.minFontSize`。
  - page：elements（elementId 唯一、elementType ∈ text|shape|line|image|table|chart、bounds、role、各类型专属字段）、`expectedOverlaps`、`overlapMode`、`background`（hex/`$ref`/{solid}/{image}）、`safeArea`。
  - **line 的 bounds 可省略**（v0.3，D1）：校验放行，normalizePage 用 points AABB 推导。
- `resolveDeck(dir)`：读取 → 校验 → 返回 `{dir, deck, size(默认960×540), theme, colors, textStyles, minFontSize(默认12), safeAreaOf(page), resolveColor, styleOf, pages:[{file,ref,page,name,index}]}`。**读时快照**——页面 yaml 被外部改写后必须重新 resolveDeck（autoDeclare 流程已如此做，见 2.6）。
- `styleOf`：`style: "$name"` 引用 theme.textStyles + 页面内联字段覆盖（合并顺序：ref → own）。

### 2.2 layout.js — 三端共享度量（渲染/校验/导出）
- `charWidth`：CJK 1em / 空格 0.4em / 数字 0.6em / Latin 0.6em（bold 0.63）/ 全角标点 1em / 其他 0.65em（v0.3 偏宽保守档）。
- `wrapLines`：CJK 字符级 token + Latin/数字词级 + **标点禁则**（行首不落 `，。、！？；：）》」…`；行尾不落 `（《【「`）。
- `measureText` / `textMetricsOf`：输出 textW/textH/lines/**lineWidths**/overflowX/overflowY。**overflowY = round(高 − 容器高)，>1px 即溢出**（统一阈值 FIT_TOL=1，见 export）。
- `normalizePage`：页面元素 → 统一快照对象（id/type/bounds/role + 类型专属字段 + text metrics）。**三端（render/verify/export）共用** → 度量一致是"verify 通过 ⇒ 导出不缩字"的根基。

### 2.3 render-html.js — 预览 + layout.json
- 每页 → `preview/<NN>_<slug>.html`（单页，含内联页面背景）+ `preview/deck.html`（整览，共享 style + 各页内联背景；修复过"拼合丢样式"缺陷）。
- `layout.json` = **数字审阅的唯一数据源**：`{size, theme{colors,textStyles,grid,safeArea,minFontSize}, pages:[{index,file,name,background,safeArea,expectedOverlaps,overlapMode,elements:[snap]}]}`。
- snap 记录每元素 id/kind/bounds/role + 专属字段（text 含 style+metrics+text；shape 含 fill/rotation；line 含 points…）。
- `debug=true`：文本描边 + **安全区参考框**（`.sa-guide` 蓝色虚线，v0.3）。

### 2.4 verify.js — 断言引擎与美学层
`analyzePage(page, size)` 产出 findings（severity: error/warning/confirmed/suggestion）：

| 断言 | 级别 | 说明 |
|---|---|---|
| out-of-page（页面边界） | ERROR | 超页面边界（放映不可见）——**永远不可声明**（出血设计见 docs/01 C11 待议）|
| out-of-page（安全区） | ERROR / confirmed | 超 safeArea 但页面内 → **声明制**：命中 `expectedOutOfSafeArea` → confirmed（✓ 预期出界），未命中 → ERROR（提示加入声明）|
| text-overflow | ERROR | wrap 看垂直（overflowY>1）/ wrap=false 看水平 |
| content-collision | ERROR | 内容面×内容面（text/table/chart），**不可声明豁免** |
| unexpected-overlap | ERROR | 警告级重叠未命中 expectedOverlaps（声明制） |
| expected-overlap | confirmed | 命中声明 → ✓ 不出现在错误/警告 |
| overlap（warning） | warning | line×任意（引线/箭头）与 内容×承载（shape/image 作底板）|
| near-align / hotspot / density | warning | 对齐启发式/密集区/密度 |
| aesthetic-* | suggestion | 8+3 条：重心/外边距/列数/间距节奏/网格/字号层级/主题颜色/文本密度 + **对比度**（WCAG，D6）+ **孤字**（末行 <1.5×fontSize，D7）+ **背景图无 safeArea 提示**（D5）|

> 声明维度（v0.3.2 统一为"空间断言=设计意图声明制"）：重叠 = `expectedOverlaps`（可一键 autoDeclare）；安全区出界 = `expectedOutOfSafeArea`（**必须手工**，id 防呆）；页面出界 = 绝对（C11 待议）。

角色推断 `roleOf`：显式 role 覆盖；默认 text/table/chart=content、shape/image=background、line=line；`decoration` 完全豁免 overlap 报告。
`collectDeclarable(page, size)`：收集"警告级未声明重叠对"（供 autoDeclare；不含 content-collision、不含已声明、不含 decoration）。

### 2.5 layout.json 语义（三端契约）
- 渲染器写、verify 消费、**可选**与导出 .pptx XML 做产物快照交叉验证（tools.js `snapshotPptxShapes`：读 out.pptx zip，数 spTree 顶层形状——仅一致性提示，不算门禁）。
- 警告：**pptx 产物快照不是布局断言**（导出几何 = 中间层几何，因导出器与校验用同一 normalizePage；真正的"产物档"增强待 R2）。

### 2.6 autodeclare.js — 一键声明（D2）
`applyAutoDeclare(ctx, layout)`：逐页 collectDeclarable → `YAML.parseDocument` **只 setIn expectedOverlaps**（保留页面其余注释，规避 C3-safe_dump 全量重排问题）→ 写回 → 返回 `[{page, added, file}]`。
**调用方必须重新 resolveDeck 再渲染**（resolveDeck 是读时快照）——tools.js 已如此；smoke 也如此断言。

### 2.7 export-pptx.js — 主引擎（pptd）
- 手写最小 OOXML：content-types / rels / presentation / slideMaster / slideLayout / theme / slides；1px=1pt，EMU=pt×12700。
- 元素映射：text→`p:sp`（txBody，auto-fit）、shape→`p:sp`（rect/roundRect/ellipse/triangle + rotation）、line→`p:cxnSp`（straightConnector1 + tailEnd 三角箭头）、image→`p:pic`（blipFill 嵌入）、table→`graphicFrame a:tbl`、chart→**矢量拼绘**（bar=矩形、line=连接线+圆点、pie=饼形 `prst=pie` 带 adj1/adj2）。
- 页面背景：`p:bg` 原生（solidFill / blipFill + 媒体嵌入 + rels，v0.3 修复）。
- `out`：**绝对路径原样使用 / 相对路径相对 deck 目录**（E1）。
- **auto-fit 与下限**（E2 修复）：只缩当 `overflowY > 1`（与 verify 同阈值）→ verify 通过 ⇒ 不缩字；缩小下限 = `min(原字号, theme.minFontSize)`（默认 12）；到下限仍溢出 → `floorHit: true` 进 report（tools.js 输出 ✗ 警告，绝不静默 <12pt）。
- **自动回退链**（C1）：tools.js `resolveEngine` 决定——auto=pptd+allowFallback；pptd 硬失败 → python-pptx 兜底（报告醒目标注降级）；显式指定不回退。
- **audit 回读断言**（D2）：audit 档导出后自动读产物 OOXML，校验页数/尺寸（EMU 精确）/最小字号 ≥ minFontSize，逐项 ✓/✗ 追加进报告。

### 2.8 import-pptx.js — 导入器（内容保真、版式近似）
- `relsOf`：正确下钻到 `Relationships` 子节点取 Relationship（修复过"层级错"）。
- `decodeXml`：UTF-8/UTF-16LE/BE BOM 自动识别（兼容 WPS 导出的 UTF-16 rels，P2）。
- **P0-1 保样式（v0.4.0）**：theme1.xml clrScheme → schemeClr 映射；shape fill（solidFill + **gradFill 渐变归一末 stop 主色**，stops 保留）/line（a:ln w/color）；文本 rPr（sz/b/i/color/font·latin+ea/align·pPr algn/lineHeight·spcPct）全量映射；`import-styles.json` 原始样式清单（渐变 stops/阴影）；deck.yaml theme 聚合建议块（colors 高频 + textStyles 字号→title/body/label）。
- 背景三层识别：slide 级 `p:bg`（blipFill 提取 + solidFill/schemeClr 背景色）→ 满页图 ≥95% 提升为背景 → layout 级背景 fallback；输出 `background:` 字段。
- elementId 去重（`-2/-3` 后缀，P5）；真实媒体提取（非占位）。
- **D4 safeArea 探测**（v0.3.2）：`detectBands` 统计跨页重复元素签名（≥60% 页数同位置）→ 顶部/底部 30% 带 → deck.yaml **注释**写入 `# safeArea: {top, bottom}`（不自动启用）+ 导入报告提示。
- 近似映射：roundRect/rotation 保留、渐变→主色（stops 保留在 styles.json）、chart→文本占位并明示。
- ⚠ 依赖 xmljs 属性解析（v0.4.0 修复：**支持带空格属性值**，如 typeface="Microsoft YaHei"——此前被空格拆坏；此修复对导出/回读/导入全链路生效）。

### 2.11 templates.js — 模板库（双轨：骨架层 + 真相层，v0.9.0）
- **模板 = 目录包** `templates/<id>/`：`template.yaml`（元数据 + **styleAudit** 视觉审计）+ `deck.yaml`（骨架层，theme/页面母版，**机器可验证**）+ `pages/_*.yaml`（参考母版，不注册不进门禁）+ `media/` + `preview.png`（缩略图）+ **真相层** `template.pptx`（原始文件，零失真）+ `previews/NN.png`（Office 真渲染整页，1920×1080）。
- **registerTemplate(dir, opts)**（外部模板收纳）：resolveDeck 校验 → 页面拷为 `_NN_` 母版 → media 复制 → 洗涤（① 出界元素批量写 expectedOutOfSafeArea ② autoDeclare 重叠 ③ 剩余错误按类型统计进 meta.cleanup）→ 缩略图（模板目录自身渲染 + Edge headless）→ **真相层**（检测 `dir/source.pptx` 或显式 `opts.sourcePptx` → template.pptx；有 Office 则 `renderPptxToPng` → previews/；失败不阻塞）。
- **materializeTemplate(dir, id)**（物化工作区）：拒绝覆盖已有 deck.yaml → 正式页 `pages/01_opening.yaml`（首母版副本，注册进门禁；pageType→content）→ 母版页 `_` 前缀不注册 → media 复制 → **参考层拷贝** `reference/{template.pptx,previews/audit.yaml}`（工作区自包含）→ deck.yaml 顶部注入 `referenceTemplate`（id/name/source/previews 清单/audit 引用；**非渲染字段**，schema 轻校验）。
- **styleAudit 设计时声明**（`ppt_template_styleaudit`）：模型 read_image 看 previews 真渲染 → 视觉理解（palette/fonts/layout/decorations/pagesReviewed/notes）写回 template.yaml → materialize 复制为 reference/audit.yaml → 每次"按模板做"直接读缓存，零重复视觉成本。
- **语义**："按模板做" = "参考用户给的 ppt 制作"：创作前先看 reference/previews/*.png（真身）+ reference/audit.yaml（审计缓存），再动手；无 reference（内置模板/无 Office 收纳）退化为骨架层 + audit 缺失说明。

### 2.12 msrender.js / preview-server.js — Office 真渲染通道 + 对话内预览
- **msrender.js（v0.8.0）**：`findPowerPoint()`（POWERPNT.EXE 候选路径探测，无则 null → 通道自动隐藏）；`renderPptxToPng(pptx, outDir, {width,height,timeoutMs})`——写 BOM ps1（Windows PowerShell 按 GBK 读无 BOM 文件会乱码中文路径）→ spawn powershell.exe -File → COM `Presentations.Open(只读)` + 逐页 `Slides.Item(i).Export(...,'PNG',1920,1080)` → 解析 `OK:<n>`；安全：只读打开、finally Quit、超时 SIGKILL 并清理残留 POWERPNT。
- **用途三点**：① 理解用户原稿（参考任务先看后做，工作流 6a）② 成品视觉审核（导出后审核真实观感，audit 档自动联动）③ 模板真相层整页（2.11）。
- **preview-server.js（v0.6.x）**：`buildPreview(dir)` → 预览根 `~/.dsh/ppt-studio/preview/<token>/`（pages/ + media/ 复制 + .meta.json 源映射）；`registerPreviewRoute` 在 webServer 注册**无尾斜杠** prefix `/ppt-preview`（prefix 语义是前缀匹配，带尾斜杠永不命中）；`resolveToken` 持久回退。

### 2.14 surgical.js — 手术模式（v0.10.0，候选 B：结构精确贴模板）
- **语义**：以模板 .pptx 为底版，把工作区（deck）内容注入模板页文本/表格槽；其余页**内容逐字节不变**（解包 sha256 验证）；重打包输出。与双轨互补（双轨=风格参考，手术=结构保真）；与 ppt_export 并存（两条成品路径，互不影响）。
- **管线**：`scanSlideXml`（spTree 顶层文本 sp / table frame 槽，<a:t> 记录**绝对位置**；跳过 grpSp；无 xfrm 槽与非文本框纯序号槽排除）→ `matchByDistance`（模板槽↔deck 元素贪心最近配对，bounds 数组/对象兼容；页码占位元素排除）→ `patchSlideXml`（**字符串切片只改 <a:t> 区间**——首 run 承载、余 run 置空保留 rPr 链；`escapeXml` 转义；`normText` 空白归一比较：导入/多 run 拼接差异不算改动）→ `surgicalPatch`（slide 顺序 = presentation sldIdLst + rels；页映射 surgicalMap/map 缺省 i↔i；zip 重打包保序）→ `verifySurgical`（未手术条目内容 sha256 对照）。
- **保真根源**：只动 a:t 区间 → rPr/几何/渐变/字体/图片/组合 100% 原样；"未动页内容哈希一致"是可验证的硬承诺（zip 重压缩后字节不同，故粒度 = 条目解包内容）。
- **v1 边界**：文本+表格；grpSp 内部/图片/新增页不注入（报告）；表格行数超出警告；rels 增量/新增页合并留 v1.1。

### 2.15 候选 C 几何闭环（v0.11.0：custGeom/alpha/形状内文本）
- **custGeom**（自定义几何，模板曲线装饰真身——简约商务 97 个实证）：import 解析 pathLst（commands: moveTo/lnTo/quadBezTo/cubicBezTo/arcTo/close + path w/h 路径坐标空间，**抽象单位原样保留不除 EMU**）→ PPTD `shape.path`；render 转 SVG `<path>`（viewBox 非等比拉满 bounds；arcTo → SVG A 命令弧终点几何转换：中心=起点−半径×角度向量，y 向下顺时针）；export `<a:custGeom>` 命令直通（几何零损失）。
- **alpha**（透明度）：solid/渐变 stop `<a:alpha val>` → fill `{color, alpha}` 或 stop `alpha`（0-100）；render `hexToRgba`；export srgbClr/gs 内 `<a:alpha>` 回写。
- **形状内文本**（非 rect 形状带文本，v0.11 修复 isText 抢先：custGeom 带文字不再整形状变文本）：`_shapeText` 提取为与形状同 bounds 的独立 text 元素（居中）——椭圆序号"1/2/3"等文本复活（20 个实证）。
- **关键修复**（回环测试暴露）：normalizePage shape 分支需透传 `path`（否则 export 空 custGeom）。
- **边界**：master/layout 层装饰（背景层——不提取，每页复制母版装饰反而混乱）；pathFill/空 path → rect 兜底；LOGO 圆环等组合内图片细节（双轨/手术覆盖）。

### 2.16 measurement.js — M2 文本实测档（浏览器真测量，D3 落地）
- **通道**：renderDeck 预览 HTML → 注入测量脚本（`Range.getClientRects` 行盒 → 行数/内容高/`overflowY = scrollHeight − clientHeight`；`getBoundingClientRect` 几何）→ Edge `--dump-dom --virtual-time-budget=2500 --user-data-dir=<独立>` 提取 `#__ppt_measured` JSON → `preview/measured.json`。
- **性能（D5 基准）**：100 页 render 70-406ms；measure **220-320s**（顺序 3.2s/页；优化链：并发 4 + 每进程独立 user-data-dir（共享 profile Singleton 锁串行化是首轮大坑）→ 2.2s/页；budget 减小无益（虚拟时间快进非线性））。20 页常用 ≈ 45s。
- **交叉语义**（verify.js `measuredCrossCheck`）：实测溢出且估算未报 = **error（估算漏报——M2 核心捕获）**；实测复现 = warning；估算报但实测通过 = relief warning（字体差异人工确认）；行数差异 = suggestion；旋转元素排除几何漂移。`ppt_verify measured=true` 默认关闭（老行为不变）。
- **诚实边界**：测量 = Chromium 排版真值（系统字库），仍非 PowerPoint 引擎；与 ppt_shot 同渲染链（字体/尺寸差异同源）。

### 2.17 crosscheck.js — M3 数据连贯（跨页对账 + 证据核查表）
- 跨页数字对账：页面 text/table 文本数字+百分比提取 → 同数字跨页入组（页号+上下文，cap 30）——"同一指标多页值不一致"的发现机制（建议级，语义判断人工）。
- 证据核查表：页面 `source` 标注 → grounded / unmapped（状态机 v1；candidate/conflicted/missing 留待来源对比能力）。
- themeRef 断言（schema.js）：`$name` 引用（fill/color/style/stop/background）必须在 theme——缺失 = resolveDeck error（防字面 `$xxx` 上屏静默回退）。
- `ppt_shot overview=true`：deck.html 整览截图（N 页纵排，>30 截前 30）——跨页节奏视觉审阅。

## 3. 核心机制解读（改这些地方 = 改项目哲学，须更新 01 文件）

1. **设计意图声明制**：重叠合法性来自"设计时声明、审阅时对照"，不是元素类型。底裤 = content-collision 永不可声明。
2. **双轨审阅**：数字门禁（快、可全自动）+ 视觉审阅（截图、防估算漏报）。估算档被真实任务证明会骗过（第 6 页溢出截图才发现），视觉审阅因此是"必要"而非"可选"。
3. **声明制成本控制**：四个缓冲——`autoDeclare` 一键批量（重叠）、`declaredClosure` 嵌套闭包（相邻层声明隔层自动）、`overlapMode: lenient`（草稿）、`role: decoration`（装饰豁免重叠）+ `contrastExempt`（对比度误报豁免）。
4. **度量一致性**：三端共用 normalizePage + wrapLines；verify 的 TOL(1px) 与 export 的 FIT_TOL(1) 相同 ⇒ 门禁通过 = 导出不缩字 = 承诺兑现（14pt/12pt 下限）。
5. **引擎质量优先**：auto=pptd；python-pptx 降级为表格，仅显式切换 —— 与设计文档"自动回退链"存在 C1 冲突（待确认，见 01 文档）。

## 5. 已知边界（诚实声明，README §已知边界 同步）

- 文本度量 = 估算档（保守系数）；**实测档（渲染回读精确测量）为下一里程碑 R1**。
- chart 在 python-pptx 引擎下降级为表格；pptxgenjs 第三引擎未实现。
- 导入器不做布局逆推（内容保真、版式可从新）；渐变/阴影/动画/超链接不支持。**模板双轨（v0.9）缓解**：模板类场景直接看真相层（template.pptx + previews 真渲染），不依赖导入近似；导入近似仅剩"从零改版"场景的参考价值。
- **模板参考通道依赖 Office**：无 Office 时真相层缺失 → 退化为 YAML 骨架 + styleAudit（如果有）；收纳时无 Office 也不生成 previews/。
- client 端 dsh 网页内嵌预览面板未实现（设计 §8 已拍板形态，属里程碑 M4）。
- 无 LibreOffice/Office 环境下无法本地把 .pptx 转 PDF/PNG；视觉验证靠 ppt_shot（预览 HTML）+ 用户实机打开。
- verify 的启发式建议（对比度/孤字/安全区）只处理实底颜色与估算换行；渐变/图片上文字不参与。

## 6. 性能与规模（实测记录）

- 19 页 / 530+ 元素 deck：render+verify ≈ 秒级；export ≈ 秒级；无阻塞项。
- **M2 基准（v0.12，D5 实测 100 页）**：render 70-406ms；**measure 220-320s**（顺序 3.2s/页 → 并发 4 + 独立 user-data-dir 2.2s/页；budget 缩小无益）；20 页常用 ≈ 45s。
- 截图：每页一次 Edge 启动（临时 profile），多页串行——100 页 deck 会慢（路线图：并发/复用 profile 池）；**整览截图（overview）单次一次性**。
- zip 用纯 JS deflate（zips.js），导出大媒体（>10MB 图片）时内存与耗时需关注（路线图：流式写/原样复制）。
- 未设 scale 上限校验：超大尺寸 deck（>4096px）Edge 截图可能超限（路线图：scale 探测）；overview 整览 >30 页自动截前 30。
