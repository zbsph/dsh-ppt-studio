## 已知导致视觉失真的因素（按影响排序）

1. **自选图形 prst → 矩形**（箭头/圆角/图标等 100+ 形状按 rect；custGeom 同理）——影响图标/箭头/装饰形状。
2. **渐变填充归一为末 stop 主色**（gradFill → 单色；stops 记录在 import-styles.json）——影响按钮/胶囊/背景弧带。
3. **特殊字体回退**（PPT 内置字体/手写体缺失 → 浏览器渲染 tofu □□□）——文本内容保留，视觉字形不同。
4. **背景层不完整**：仅识别 slide 级 p:bg 与 ≥95% 满页图；蒙层/前景盖图/背景组图按元素近似。
5. **SmartArt → 文本占位**；图表 → 文本占位（数据在 xml 中，可重建）。
6. **文本块宽度 vs 字体度量差** → 断行位置与源不同（制作时可调框宽）。
7. **裁剪图 srcRect 忽略**（按 fit 拉伸）。
