## [0.3.2] 2026-09-04 —— C3 修订为"出界分级声明制" + D1–D6 全部落地

### 目的
用户对 C3 提出关键设计观点：**与其"角色豁免"（decoration 全豁免出界），不如与重叠同构的"声明制"**——设计时把有意落在页眉页脚带的元素列为"意料之内"，审阅时对照，命中即（确认）通过，未命中即错。设计者必须逐元素思考"这是否合理"，而不是贴个角色标签就不管了（后者正是 C2 担忧的放大版）。同时 D1–D6（意图自证/audit 范围/实测档关系/安全区探测/性能/发布）按用户认可的倾向落地。

### 改动
1. **出界分级声明制（C3 修订）**：
   - 新页级字段 `expectedOutOfSafeArea: [idA, ...]`：有意落在模板页眉页脚带/安全区外的元素，**逐元素手工声明**；id 必须存在于本页（schema 防呆，声明无效当场报错）。
   - verify 分级：超**页面边界**=永远 ERROR（不可声明）；超**安全区**（仍在页面内）=声明制——命中 → confirmed（✓ 预期出界，计数入报告头），未命中 → ERROR（错误信息指向如何声明）。
   - **回滚 v0.3.1 的 decoration 豁免出界**：`role: decoration` 收窄为只豁免重叠（"装饰性"本身是设计意图声明）；页眉页脚带元素走 expectedOutOfSafeArea。
   - autoDeclare **不自动生成出界声明**（出界=个案思考，与批量重叠声明分工）。
2. **D1 意图自证**：提示词（铁律 2 尾 + 入门段）规定 autoDeclare 写入后输出声明清单，每对附一句意图；说不清意图的对子必须改布局而不是声明。SCHEMA_REF 同步。
3. **D2 audit 档补完**：`ppt_export` 在 audit 档自动追加**回读断言**（产物 OOXML：页数/尺寸精确 EMU/最小字号 ≥ minFontSize），报告逐项 ✓/✗；提示词铁律 11 规定 audit 行为（禁 autoDeclare、强制 shot+读图、核对回读断言、素材来源标注）。
4. **D4 导入安全区探测**：`detectBands` 统计跨页重复元素（≥60% 页数同位置）→ 顶部/底部带 → deck.yaml 写入注释 `# safeArea: {top, bottom}`（**不自动启用**）+ 导入报告提示。
5. **D3/D5/D6**：决策记录（docs/01 §6）。

### 验证
- smoke 51 → **60 断言**（+9：未声明出界含 decoration 报错、超页报错、一级声明命中 confirmed、声明后 decoBand 消错、超页声明无效仍错、坏 id 防呆、D4 带探测回环、重验计数与错误集合）。
- 全量 smoke 全绿；回归脚本不动（WPS fixture 2 页 < 3 页不触发带探测，符合设计）。

### 影响 / 后续
- 语义统一为"空间断言 = 设计意图声明制"（重叠 + 安全区出界两个维度），角色制只剩 decoration 的重叠豁免。
- C11（出血 bleed）记入争议清单：超页不可声明是一致性代价，真实需求出现时再议。
- audit 档的"证据链/数据来源核查"仍属 M3，不在本版。

## [0.3.1] 2026-09-04 —— 冲突清单三项拍板落地（C1/C2/C3）

### 目的
用户对 docs/01 §5 冲突清单的三项真冲突作出决定（"按文档建议默认推进" + 三项选择），本轮把决定从"文档里的倾向"变成"代码事实"。

### 决定与改动
1. **C1 自动回退链（用户选"实现自动回退链"）**：
   - `resolveEngine(engine)` 语义：`auto/缺省 = pptd 优先 + allowFallback`；显式 `pptd` / `python-pptx` 尊重用户选择不回退。
   - `ppt_export`：pptd 硬失败 → 检测 python-pptx → 有则兜底导出，报告开头 **⚠ 醒目标注降级 + pptd 失败原因 + 图表降级提醒**；无 python → 报原因 + 提示。绝不静默。
   - python-pptx 引擎 `out` 同步支持绝对路径（isAbsolute）。
2. **C2 audit 禁 autoDeclare（用户选"audit 禁用"）**：`ppt_verify autoDeclare=true` 在 audit 质量档（项目级 state.json 或会话级任一为 audit）直接拒绝并解释原因；`blockedByAudit` 纯函数导出可测。
3. **C3 decoration 豁免出界（用户选"role: decoration 豁免"）**：verify out-of-page 检查跳过 `role: decoration` 元素——装饰层可合法落在模板页眉页脚带/安全区外；内容元素的 safeArea 门禁保持不变。

### 验证
- smoke 47 → **50 断言**（新增：decoration 在安全区外不报出界、resolveEngine 三段语义、blockedByAudit）。
- 全量 smoke 全绿；docs/01 C1/C2/C3 状态更新为 🟢 已定；README/SCHEMA_REF 同步。

### 影响 / 后续
- C1 使"图表降级表格"在 auto 模式下**可能自动发生**——只发生在 pptd 硬失败（异常）时，报告必标注；若用户希望"降级前问一句"，可在 M1 加 pause 点（未做，默认自动+标注）。
- C3 后安全区门禁只对内容生效；"装饰元素混过出界门禁"的风险由视觉审阅兜底（quick 档除外，已是既定取舍）。

## [0.3.0] 2026-09-04 —— 真实任务反馈 8 项 ★ 修复 + 背景全链路 + 长期工程化

### 目的
用户以"产能项目 PPT 绘制"（19 页，13 份 docx 材料 + 参考模板）实测整套工作流，输出《测试反馈_产能PPT任务.md》：**主链路一次走通，返工集中在"校验-修复"循环**，70% 返工源于对 DSL 规则/度量的不熟悉，30% 是工具摩擦。本轮把 8 个 ★ 项全部插件级修复。

### 改动
1. **背景图全链路（上一轮未完 + 本轮回归）**：schema/render/export(p:bg 原生)/import（slide p:bg → 满页图提升 → layout 兜底 三层识别）。
2. **B2 ★ schema 自述**：新工具 `ppt_schema`（内置 DSL 语法速查：deck.yaml/元素字段/主题 token/safeArea/声明/审阅约定）+ `ppt_new`（`scaffoldProject` 一键生成 3 页可跑样例：主题 token、色块衬底+expectedOverlaps、line 无 bounds、safeArea 范本；已存在 deck.yaml 拒绝覆盖）；工作流提示词新增【入门】段。
3. **D2 ★★ 声明成本**：`ppt_verify autoDeclare=true` → `autodeclare.js applyAutoDeclare`：collectDeclarable 收集警告级未声明重叠对 → `parseDocument` setIn（保留页面注释）→ 重新 loadCtx + render + verify；报告"已写入声明 + 剩余错误"。
4. **D4/E2 ★★ 双度量**：保守字符宽度（CJK 1em/拉丁·数字 0.6em/空格 0.4em/其他 0.65em）+ 三端（render/verify/export）共用同一 normalizePage/wrapLines 度量；导出 auto-fit 阈值从 `> boxH*0.02` 改为 `> 1px`（与 verify TOL 相同）⇒ **verify 通过 ⇒ 导出不缩字**。
5. **E2 缩字下限**：导出缩字下限 = `min(原字号, theme.minFontSize)`（默认 12pt）；到达下限仍溢出 → `floorHit` 标记，工具输出 ✗ 警告（绝不静默 <12pt）。
6. **D5 ★ 安全区**：`theme.safeArea` + 页级 `safeArea` 覆盖；verify 把安全区外判为 out-of-page ERROR（报"超出页面安全区"）；`ppt_render debug=true` 画 `.sa-guide` 参考框；图片背景未配安全区给 `[·]` 建议。
7. **E1 ★ out 绝对路径**：`exportPptx out` 绝对路径原样使用（`isAbsolute`），相对仍相对 deck 目录。
8. **D1 line bounds 可选**：schema 允许 line 省略 bounds；normalizePage `boundsOf` 用 points AABB 推导（w/h≥1px）。
9. **D6/D7 启发式建议**：对比度（WCAG 相对亮度，<3.0 提示，<1.8 标"接近不可读"）；自动换行末行 <1.5×fontSize 提示孤字/显式断行。
10. **工程化**：docs/ 档案库（本目录）；git 版本控制；fixtures/ + `scripts/regression-real.mjs` 真实回归；`npm test` 脚本。

### 验证
- smoke 30 → **47 断言全绿**（新增 17：safeArea 出界/区内、line 推导、autoDeclare 写入+重验、对比度、孤字、绝对路径、floorHit、scaffold 生成+拒绝覆盖、SCHEMA_REF 内容、debug 参考框）。
- **真实回归**：19 页产能 deck resolveDeck+render+verify = **0 错误**；export = **0 autoFit**（E2 承诺实例化）；WPS 2 页 2 图导入正常。
- 热重载 `dev_reload_package` 生效（2 fiber active）。

### 影响 / 后续
- 回到"表格自动回退"张力见 docs/01 C1；autoDeclare 与声明制的张力见 C2；safeArea 与页脚装饰元素见 C3。
- 本版刻意**不动**：签名制的"声明制本体"（声明=设计意图）、content-collision 不可豁免、18 页以上性能、导入保真度目标。

## [0.2.x] 2026-09-03 —— Quick 模式 + 引擎 auto 语义固化

### 目的

### 改动
- `/ppt quick` 命令 + `isQuickIntent` 语义（"简单/快速/quick/随便做" + PPT 语境，非 PPT 语境不误触）。

- state 默认 `quick=false`、`engine=auto`。

### 验证
