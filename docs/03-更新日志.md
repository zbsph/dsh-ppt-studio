## [0.7.0] 2026-09-04 —— 模板加载语义修正：参考素材与正式页分离（"加载被门禁拦截"根治）

### 目的
用户反馈：加载模板（ppt_new --template）后，外部模板页的"元素重叠"被 verify 门禁拦截——但那些是模板设计的**有意叠层**（声明制意义上的"设计意料之内"），且加载阶段还没有"设计"步骤。根因：**母版页被注册进工作区 deck.pages**，verify 把"参考素材"当"成品页"校验。正解不是放开校验（content-collision/出界/溢出仍是底线），而是**分离校验对象**。

### 改动
1. **校验对象分离**（materializeTemplate，可测函数；ppt_new --template 改用它）：
   - `pages/_*.yaml` = 参考母版（**不注册进 deck.pages，不进 render/verify 门禁**）；
   - `pages/01_opening.yaml` = 模板首母版的**正式副本**（注册进门禁；提示先 `ppt_verify autoDeclare=true` 声明模板固有有意叠层，剩余是模板原文案残留，替换即净）；
   - 模板媒体**跟随复制**（外部模板含图）。
2. **收纳洗涤升级**（registerTemplate）：新增**出界声明**（模板页超安全区元素 = 有意设计 → expectedOutOfSafeArea 批量写入）+ 剩余错误**按类型分类**（out/page/overflow/content-collision 各 N 条）记入 meta.cleanup——用户加载前就知道"预期什么"。
3. prompt 6b 更新模板工作区语义；yamlDeck bandNote 只写存在的安全区键。

### 验证
- smoke 86 → **91**（正式页单页注册+母版不进门禁、内置模板正式页 0 错误、外部模板工作区只注册 1 正式页+媒体跟随、收纳清洗出界/重叠/分类元数据）。
- 重跑 4 套外部模板收纳：深蓝质感 341→**93**（声明 8 出界 + 248 重叠；剩余 out×8/text×15/content×70 分类可预期）。

### 影响 / 后续
- 用户反馈闭环：加载模板不再被模板素材的门禁拦截；门禁只面向"你交付的页"。
- 剩余分类里的 content-collision（导入近似造成的文本框互压）在正式页替换内容时自然消除；真需要的页按 verify 修正。
- 下一里程碑：手术模式（A+B）。

## [0.6.3] 2026-09-04 —— 发布友好性：预览 URL 动态化 + 硬编码路径审计

### 目的
用户提出发布视角两点：绝对路径 URL 对不同部署用户是否适配？此前修复是否走了捷径、是否伤及既有功能？本轮做**证据级审计 + 动态化**。

### 改动
1. **预览 URL host 动态化**：新增 `previewOrigin(ws)`（可测导出）——origin 完全来自当前 dsh 实例的 webServer 契约 host/port（动态适配任意用户端口/主机名）；`0.0.0.0/::` 监听回退 127.0.0.1；无 ws 时降级相对路径。此前硬编码 `127.0.0.1:3080` 是真实缺陷。
2. **硬编码路径审计**：grep 源码/脚本/模板——模板零外部路径（`Desktop/D:\C:\` 零命中）；Edge 候选路径（3 处）为"探测候选"（存在才用）非绑定；regression-real/dbg-media 的机器路径改为 `PPT_REAL_DECK`/`DBG_LAYOUT` 环境变量（缺省回退 + 跳过）。输出文档补"远程部署说明"。
3. **回归证据**：本轮修复（safeBounds/缩略图/cleanup/注入断言）全部有 smoke 断言覆盖（86→87），无走捷径（无放宽 schema、无跳过校验、无静默降级新路径——唯一的"声明清理"是设计内行为）。

### 验证
- smoke 87/87；WPS 真实回归 ✓；previewOrigin 四分支断言（127/0.0.0.0 回退/无 ws/localhost）。

### 影响 / 后续
- 远程部署场景的"浏览器访问地址≠监听地址"（如反代）由同源相对路径兜底；client 面板（B 阶段）将从 window.location 构造 origin（完全正确的方案）。
- 发布打包清单（files: lib/vendor/templates/README）无机器绑定。

## [0.6.1] 2026-09-04 —— 梵高任务反馈修复：链接可点（P0）+ 图表全零（P1）+ 深色背景误报（P7）

### 目的

4. **P7 背景 $ref 解析**：`resolveBackground` string 分支补 `resolveColor`（渲染 CSS 与 layout 记录一并修正——深色底不再白底误算对比度）。

### 验证
- smoke 80 → **84**（单列兼容值 [72,55]、全零告警非空/正常为 null、4 套模板图表值非零、$ref 背景 hex）。
- 宿主端到端：stage 工具确认 `webServer.port=3080` + 绝对预览 URL HTTP 200。

### 影响 / 后续

## [0.3.2] 2026-09-04 —— C3 修订为"出界分级声明制" + D1–D6 全部落地

### 目的
用户对 C3 提出关键设计观点：**与其"角色豁免"（decoration 全豁免出界），不如与重叠同构的"声明制"**——设计时把有意落在页眉页脚带的元素列为"意料之内"，审阅时对照，命中即（确认）通过，未命中即错。设计者必须逐元素思考"这是否合理"，而不是贴个角色标签就不管了（后者正是 C2 担忧的放大版）。同时 D1–D6（意图自证/audit 范围/实测档关系/安全区探测/性能/发布）按用户认可的倾向落地。

### 改动
1. **出界分级声明制（C3 修订）**：
   - 新页级字段 `expectedOutOfSafeArea: [idA, ...]`：有意落在模板页眉页脚带/安全区外的元素，**逐元素手工声明**；id 必须存在于本页（schema 防呆，声明无效当场报错）。
   - verify 分级：超**页面边界**=永远 ERROR（不可声明）；超**安全区**（仍在页面内）=声明制——命中 → confirmed（✓ 预期出界，计数入报告头），未命中 → ERROR（错误信息指向如何声明）。
   - **回滚 v0.3.1 的 decoration 豁免出界**：`role: decoration` 收窄为只豁免重叠（"装饰性"本身是设计意图声明）；页眉页脚带元素走 expectedOutOfSafeArea。
   - autoDeclare **不自动生成出界声明**（出界=个案思考，与批量重叠声明分工）。
2. **D1 意图自证**：提示词（铁律 2 尾 + 入门段）规定 autoDeclare 写入后输出声明清单，每对附一句意图；说不清意图的对子必须改布局而不是声明。SCHEMA_REF 同步。
3. **D2 audit 档补完**：`ppt_export` 在 audit 档自动追加**回读断言**（产物 OOXML：页数/尺寸精确 EMU/最小字号 ≥ minFontSize），报告逐项 ✓/✗；提示词铁律 11 规定 audit 行为（禁 autoDeclare、强制 shot+读图、核对回读断言、素材来源标注）。
4. **D4 导入安全区探测**：`detectBands` 统计跨页重复元素（≥60% 页数同位置）→ 顶部/底部带 → deck.yaml 写入注释 `# safeArea: {top, bottom}`（**不自动启用**）+ 导入报告提示。
5. **D3/D5/D6**：决策记录（docs/01 §6）。

### 验证
- smoke 51 → **60 断言**（+9：未声明出界含 decoration 报错、超页报错、一级声明命中 confirmed、声明后 decoBand 消错、超页声明无效仍错、坏 id 防呆、D4 带探测回环、重验计数与错误集合）。
- 全量 smoke 全绿；回归脚本不动（WPS fixture 2 页 < 3 页不触发带探测，符合设计）。

### 影响 / 后续
- 语义统一为"空间断言 = 设计意图声明制"（重叠 + 安全区出界两个维度），角色制只剩 decoration 的重叠豁免。
- C11（出血 bleed）记入争议清单：超页不可声明是一致性代价，真实需求出现时再议。
- audit 档的"证据链/数据来源核查"仍属 M3，不在本版。
