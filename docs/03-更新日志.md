## [0.14.4] 2026-09-04 —— 修复：预览路由从未真正注册（ws.register 是异步）

### 目的
v0.14.3 撤画廊后 `/ppt-preview` 仍 0 字节 404（=webServer 默认 404，路由未注册）——**根因确认（宿主内探针三层证据链）**：① webServer `prefixes` 路由表 24 条无 /ppt-preview；② **手动同步调 register 无效**；③ **`await ws.register(...)` 后注册成功**（25 条 + has=true + 清理正常）——**ws.register 是异步的（返回 Promise<disposer>）**，而**自 v0.6.3 首次引入预览路由起注册从未 await**（smoke 19 节只测 buildPreview 文件生成、不测 HTTP 端到端——长期盲区，v0.14.4 起修正认知并纳入验证）。

### 改动
1. **registerPreviewRoute 异步初始化重写**：`ws.register` 返回的 Promise settle 后才写入 ROUTE_REG.unreg；**清理早于注册完成**时用 cancel 标记（完成后自反注册）——refcount/幂等语义保留（v0.14.2）。
2. smoke 29 节升级为 **async-register 语义**（fake register 返回 Promise<disposer> + 等待 settle 断言）——锁死"未 await 注册"类缺陷。

### 验证
- smoke 128/128（async 语义断言）。
- **端到端（重启后，决定性）**：staging 探针查 webServer prefixes 表应含 /ppt-preview；HTTP `/ppt-preview/<token>/...` 应 200/12B-notFound（token 语义分支），非 0B。

### 影响 / 后续
- **教训（重大）**：任何 webServer 资源注册必须 `await ws.register` 且 **smoke 必须覆盖 HTTP 端到端**（staging 探针可查宿主路由表——工具化验证手段已建立）。
- ppt_preview（v0.6.3 起）实际从未能打开过——用户今日点画廊才第一次暴露；修复后预览链接首次真正可用。

## [0.14.2] 2026-09-04 —— 修复：双装配源导致 duplicate /ppt-preview（重启崩溃）

2. 幂等行为 smoke 三态（fake webServer 双实例：只注册一次 / 单 dispose 不卸载 / 最后 dispose 卸载）。

### 验证

- 端到端：重启后（幂等注册）不再 duplicate；画廊 URL 200 + 资源路由白名单（见下轮验证）。

   - verify 分级：超**页面边界**=永远 ERROR（不可声明）；超**安全区**（仍在页面内）=声明制——命中 → confirmed（✓ 预期出界，计数入报告头），未命中 → ERROR（错误信息指向如何声明）。
   - **回滚 v0.3.1 的 decoration 豁免出界**：`role: decoration` 收窄为只豁免重叠（"装饰性"本身是设计意图声明）；页眉页脚带元素走 expectedOutOfSafeArea。
   - autoDeclare **不自动生成出界声明**（出界=个案思考，与批量重叠声明分工）。
2. **D1 意图自证**：提示词（铁律 2 尾 + 入门段）规定 autoDeclare 写入后输出声明清单，每对附一句意图；说不清意图的对子必须改布局而不是声明。SCHEMA_REF 同步。
3. **D2 audit 档补完**：`ppt_export` 在 audit 档自动追加**回读断言**（产物 OOXML：页数/尺寸精确 EMU/最小字号 ≥ minFontSize），报告逐项 ✓/✗；提示词铁律 11 规定 audit 行为（禁 autoDeclare、强制 shot+读图、核对回读断言、素材来源标注）。
4. **D4 导入安全区探测**：`detectBands` 统计跨页重复元素（≥60% 页数同位置）→ 顶部/底部带 → deck.yaml 写入注释 `# safeArea: {top, bottom}`（**不自动启用**）+ 导入报告提示。
5. **D3/D5/D6**：决策记录（docs/01 §6）。

### 验证
- smoke 51 → **60 断言**（+9：未声明出界含 decoration 报错、超页报错、一级声明命中 confirmed、声明后 decoBand 消错、超页声明无效仍错、坏 id 防呆、D4 带探测回环、重验计数与错误集合）。
- 全量 smoke 全绿；回归脚本不动（WPS fixture 2 页 < 3 页不触发带探测，符合设计）。

### 影响 / 后续
