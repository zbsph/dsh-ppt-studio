## 5. 已知限制（随版本发布）

1. 无逐形状样式（阴影/高光/笔触）；开发期的强样式控制选项未纳入；
2. 手写几何由作者给出 ⇒ 单页成本更高、批量大 deck 更慢；
3. 生成器检查为**语法级**（运行期类错误仍可能漏网）；
4. 13 页手画回归语料**不随包发布** ⇒ 该回归只在仓库内可跑；包内只发 `lib`；
5. `unknown-key` 仍是**测试链守卫**，尚未进入每页门禁报告。

## 6. 遗留与回滚

- **遗留 1**：已发布的 1.2.0 构建自 tag `976e97e`，**不含**其后 `9cb5184` 的"更新日志同名标题"排版修复 ⇒ 若希望包内文档也干净，需发 **1.2.1**（功能无差异）。
- **遗留 2**：`systemPrompt` 出现在 `inject` 声明中，但源码未发现直接调用点（无害，列为可选清理）。
- **遗留 3**：装配语义（C）只核到"名字与结构仍在"层，未逐行验证行为等价。
- **回滚点**：`pre-release`、`pre-adapt-D/E/F`、`pre-release-1.2.0`；上一版 tag `v1.1.5`。
- **平台事实**：桌面 profile 由 Electron 独占管理（`dsh plugin --profile desktop …` 会被拒 ⇒ 桌面端插件变更只能走应用「插件管理」）；`web` / `headless` profile 可用 CLI 管理。
